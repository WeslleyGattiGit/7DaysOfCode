# 🎬 Consuming Movies API — #7DaysOfCode

Projeto desenvolvido como parte do desafio **#7DaysOfCode**, com o objetivo de praticar o consumo de APIs utilizando Java e Spring Boot.

A aplicação consome a API do [The Movie Database (TMDB)](https://www.themoviedb.org/) para consultar filmes mais bem avaliados e exibir a resposta JSON no console.

## 🛠️ Tecnologias utilizadas

- Java
- Spring Boot
- Spring Web (`RestTemplate`)
- TMDB API
- Dotenv para gerenciamento de variáveis de ambiente
